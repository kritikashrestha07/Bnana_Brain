# Banana Brain – System Architecture

## 1. Project Overview

Banana Brain is a full-stack web application developed using React, Node.js and Express. It follows a client-server architecture, separating the frontend interface from backend processing.

## 2. Frontend Architecture

The frontend is developed using React and Vite. It contains reusable UI components, layouts, pages, hooks and services to organize application functionality into separate modules.

## 3. Backend Architecture

The backend uses Node.js and Express to handle application requests. It is organized into controllers, routes, repositories, services, middleware and configuration modules.

## 4. Database Architecture

PostgreSQL is used for persistent data storage. Database migrations and seed files support database organization and initialization.

## 5. External Integration

The application integrates with the Banana API, demonstrating communication between the application and an external web service.

## 6. Architectural Benefits

The separation of frontend and backend responsibilities improves modularity, maintainability, testing and future development.
